# Udemy Home Page Clone

A static clone of the Udemy home page, built with HTML and CSS to practise page layout.

## Sections

- Navigation bar (with a mobile menu)
- Course category buttons
- Flash-sale banner
- **Recommended for you**
- **Topics recommended for you**
- **Most popular** course cards

## Tech Stack

- HTML5
- CSS3
- [Font Awesome 6](https://fontawesome.com/) icons
- Google Fonts (Gabarito, Young Serif)

## Run locally

No build step is needed.

```bash
git clone https://github.com/BALASUBRAMANIYAN-S/project_of_Udemy_clone.git
cd project_of_Udemy_clone
```

Open `index.html` in a browser.

## Project Structure

```
├── index.html
└── 1.jpg ... 10.jpg     # Course and banner images
```

## Notes

- This is a practice project and is not affiliated with Udemy.
- Several images are large (up to about 9 MB each). Compress them (for example to WebP or smaller JPEGs) to make the page load faster.
- A React version of this project is in [project_of_udemy_react](https://github.com/BALASUBRAMANIYAN-S/project_of_udemy_react).
